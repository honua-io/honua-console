# Unified workspace interaction model

Tracks implementation of the approved UX-001–008 additions to server epic 6297 and Console issue 431. This extends the existing workspace and resource-first flow; it does not restore shelved builders. The original resource-first design remains historical context.

Home prioritizes local evaluation, connecting an existing deployment and continuing work. `/setup/local` explains the external local-agent handoff: the browser cannot inspect Docker or run an installer. Copying a request performs no setup. Installation uses actual selected release artifacts and returns the actual Console address. Health, approvals and specialist work areas remain available under deliberate disclosure.

A single primary conversation occupies a separate column beside the task on wide screens. Console/Studio/Processes view tabs preserve the host-owned session. Embedded Studio hides its standalone composer; standalone Studio keeps it. The conversation shows environment, selected resource and task, with precise binding identifiers available deliberately rather than dominating the task. Follow navigation stays optional; switching a view never approves or executes anything.

Primary navigation follows Home, Data & Layers, Maps & apps, Processes, Approvals and Activity. More tools retains existing work-area and operational URLs. Connection setup progressively reveals account/tenant/native settings without changing authentication defaults. Existing deep links remain supported.

Add Data uses contextual source controls and the shared conversation. The main route suppresses legacy AI/Manual controls and Describe-it intake. Choosing a connected table opens the canonical publish-layer form, which shares its versioned authorized draft with chat. File import and specialist publication continue through their existing executors. Upload bytes, connection credentials and raw page state never enter agent context. The old standalone flow component remains available to existing compatibility consumers; it is not the primary Add Data conversation.

Resource and connection reads show one actionable recovery state with technical details disclosed. Failed reads do not render a false empty tree or table. Successful empty reads retain the normal Add Data action. Partial reads may show actual available resources alongside the warning.

Narrow screens begin with collapsed navigation. The conversation moves into document flow and can collapse; it never overlays task controls. Native checkbox/details controls retain keyboard state and focus. Unsaved-edit guards, frozen prompt targets, per-tab binding, separate human approval and agent-authority projection remain unchanged.

Validation must distinguish component/rendered checks from the real external-stack journey and GIS evaluator usability testing. The completed expert disconnected review is not a user study, publication proof, or milestone sign-off.

Legacy standalone Studio builders are retired. `/studio` is the Console-hosted realtime workspace; old builder URLs offer direct workspace guidance. The active `honua-studio` editor dependency is not archived. `/operate/ai` launches the primary conversation regardless of the embed configuration.

External tab pairing is explicit and contains references only. Copying context refuses unsaved edits and does not create a turn or save a draft. The external agent verifies the actual target and uses the original revision; later navigation cannot silently change it.

UX-008 remains under qualification: map-local and shared catalog scopes are explicit; the shared advanced CAS editor requires complete authorized impact before saving. The shared visual bridge, real label/assets and publication propagation need their own evidence. Current partial work is not a milestone sign-off.
